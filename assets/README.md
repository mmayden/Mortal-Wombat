# `assets/`

Source art and audio. **Human-only — agents never write here** (AGENTS.md
rule 2). Binary and unmergeable.

Generated output (atlases, packed sheets, manifests) does not belong here
either: it is regenerable, it conflicts constantly, and it carries no review
value. It goes to `assets/generated/`, which is gitignored.

v1 ships colored rectangles, and that is a decision rather than a placeholder
apology (ADR 0013 / DESIGN.md §5.1). Do not propose replacing boxes with art
before the v1 definition of done in DESIGN.md §6 is met.
