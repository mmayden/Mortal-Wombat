# drawing-board

**Research and design work in progress. Nothing here is binding.**

Kept separate from `docs/` on purpose: `docs/` is what the project has decided,
this is what it is still deciding. Material graduates out of here when it
settles, and this folder keeps the reasoning that produced it.

| File | What it is |
|---|---|
| `RULESET.md` | The live design draft. Decisions made, and the order of what is next. |
| `2d-fighter-mechanics-deep-dive.md` | Designer's analysis of which mechanics the genre actually values, and why. Supplied research. |
| `2d-fighters-breakdown.txt` | Transcript of a video taxonomy of fighting game subgenres. Supplied research. |

Both research documents arrive at the same root axes independently — block
method, air-block permission, team size — which is why those are treated as
foundational rather than as preferences.
